# Research Reviews

This directory holds periodic zoom-out memos.

Research reviews are not experiment logs. They are steering documents that
decide whether the current branch still deserves attention.

Write or update a review after:

- 5-10 experiments;
- a branch-level positive or negative;
- a confusing sequence of local variants;
- any moment where the next step is unclear.

Each review should answer:

- What changed since the last review?
- What belief changed?
- What branch should stop?
- What branch deserves more compute?
- Are we closer to the overarching goal?
- What would count as success next?
